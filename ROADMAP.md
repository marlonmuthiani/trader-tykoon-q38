# ROADMAP.md

## Vision

Deliver Trader Tykoon Q38 in phases that prioritize trust, visibility, and operational safety before scaling into broader automation.

## Phase 0 — Discovery and planning

Status: active

Objectives:

- confirm product scope and trading assumptions
- validate risk posture and user roles
- define the architecture and operating model
- document integration boundaries and success criteria

Outputs:

- PRD
- architecture overview
- agent and contributor guidance
- design principles and review gate

## Phase 1 — Foundation and observability

Status: pending

Objectives:

- establish data model and source contracts
- define market data ingestion flow
- implement observability and health logging
- validate data quality checks and fallback behavior

Deliverables:

- source registry
- data contract definitions
- health dashboard concept
- alert and anomaly rules

## Phase 2 — Signal and review workflow

Status: pending

Objectives:

- add signal normalization and context generation
- define trade idea lifecycle
- connect strategy evaluation to review steps
- document approvals, rejections, and notes

Deliverables:

- signal catalog
- trade review workflow
- review notes and state tracking

## Phase 3 — Risk and execution governance

Status: pending

Objectives:

- formalize position sizing and exposure checks
- establish control gates before action
- define audit ledger and operational traceability

Deliverables:

- risk policy framework
- approval workflow definitions
- execution event log model

## Phase 4 — Expansion and automation

Status: future

Objectives:

- add automation for supported workflows
- expand integrations and reporting
- improve dashboarding and operational insight

Deliverables:

- automation playbooks
- broader reporting suite
- advanced monitoring and analyst tools

## Milestone gate criteria

Each phase should only advance when:

- requirements are documented
- design decisions are reviewed
- risks and assumptions are visible
- architecture remains consistent with the overall system
- stakeholders confirm the output addresses an actual need

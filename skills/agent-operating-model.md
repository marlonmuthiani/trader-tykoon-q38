# Agent Operating Model

## Objective

Maintain a clear execution model for contributors and autonomous agents working in a documentation-led project.

## Principles

- each task should be traceable to a documented need
- architecture assumptions should remain explicit
- human review gates must be visible
- no undocumented shortcuts around risk or approval boundaries

## Standard workflow

1. Identify the requirement.
2. Review the design context.
3. Update the relevant document.
4. Validate the change against the system model.
5. Record decisions and assumptions.

## Output quality standard

A work item is complete when it is understandable to a new contributor without requiring hidden context.
